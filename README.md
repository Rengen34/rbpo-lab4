# Лабораторная работа 4

Это продолжение приложения для внутренних закупок. Данные и учётные записи хранятся в H2.

## Что добавлено

- регистрация пользователей в базе;
- пароли хранятся как BCrypt-хеши;
- вход через HTTP Basic;
- CSRF-токен для `POST`, `PATCH` и `DELETE`;
- роли `USER` и `MANAGER`;
- состояния учётной записи `ACTIVE`, `LOCKED`, `DISABLED`;
- проверка владельца заявки;
- отдельные ответы 401, 403 и ошибки бизнес-правил.

Саморегистрация всегда создаёт роль `USER`. Роль `MANAGER` создаётся только при запуске из настроек окружения.

## Запуск

Нужен JDK 17 или новее. Дважды щёлкните `Запустить.cmd` и введите три локальных пароля. Пароль менеджера должен содержать не меньше 10 символов, верхний и нижний регистр и цифру.

Запуск из PowerShell:

```powershell
cd 'C:\Users\satur\Desktop\ТОХИР\Учёба МТУСИ\5 семестр\РБПО\Код\04 - Лабораторная работа 4'
$env:RBPO_DB_OWNER_PASSWORD = 'пароль-владельца-базы'
$env:RBPO_DB_PASSWORD = 'другой-пароль-приложения'
$env:RBPO_MANAGER_PASSWORD = 'ManagerPass123'
.\mvnw.cmd spring-boot:run
```

Логин первого менеджера: `manager`. Его пароль берётся из `RBPO_MANAGER_PASSWORD`.

## Регистрация и CSRF

1. Выполните `GET http://127.0.0.1:8080/api/auth/csrf`.
2. Сохраните cookie из ответа и значение поля `token`.
3. Для изменяющего запроса передайте токен в заголовке, имя которого указано в `headerName`.
4. Для защищённых адресов также укажите HTTP Basic логин и пароль.

Пример тела регистрации:

```json
{
  "username": "student_24",
  "password": "StudentPass123",
  "displayName": "Студент"
}
```

Адрес регистрации: `POST /api/auth/register`. Для просмотра токена: `GET /api/auth/csrf`.

Менеджер может посмотреть учётные записи через `GET /api/auth/accounts` и изменить состояние через `PATCH /api/auth/accounts/{username}/status`.

## Права

| Действие | USER | MANAGER |
| --- | --- | --- |
| Читать данные | Да | Да |
| Создать и опубликовать свою заявку | Да | Да |
| Изменить чужую заявку | Нет | Да |
| Управлять поставщиками и предложениями | Нет | Да |
| Выбрать предложение, завершить или отменить заказ | Нет | Да |
| Блокировать учётные записи | Нет | Да |

Все CRUD и пять бизнес-операций из третьей работы сохранены. Их адреса перечислены в коллекции `postman/lab4.postman_collection.json`.
